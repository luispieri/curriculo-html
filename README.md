# 📄 CV Digital - Luis Felipe de Pieri

Um currículo digital interativo e responsivo desenvolvido em HTML, CSS e JavaScript puro, com funcionalidades de modo escuro e exportação para PDF.

## 🌟 Funcionalidades

- **Design Responsivo**: Adaptado para desktop, tablet e mobile
- **Modo Escuro**: Alternância entre tema claro e escuro com persistência local
- **Exportação PDF**: Geração automática de PDF do currículo (disponível apenas em desktop)
- **Interface Interativa**: Navegação suave e experiência de usuário otimizada
- **Modal Responsivo**: Notificação automática para usuários mobile sobre limitações do PDF

## 🚀 Demonstração

O projeto apresenta um currículo completo com as seguintes seções:
- Informações de contato
- Resumo profissional
- Experiência profissional detalhada
- Habilidades técnicas
- Formação acadêmica
- Cursos e certificações
- Idiomas

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estrutura semântica e acessível
- **CSS3**: Estilização responsiva com variáveis CSS para tema escuro
- **JavaScript**: Funcionalidades interativas e manipulação do DOM
- **html2pdf.js**: Biblioteca para geração de PDF no client-side

## 📁 Estrutura do Projeto

```
CV_html/
├── index.html              # Página principal do currículo
├── assets/
│   ├── css/
│   │   └── styles.css      # Estilos CSS principais
│   └── js/
│       └── script.js       # Scripts JavaScript
└── README.md               # Documentação do projeto
```

## 🔧 Como Usar

### 1. Visualização Local

1. Clone ou baixe o repositório
2. Abra o arquivo `index.html` em seu navegador preferido
3. O currículo será exibido com todas as funcionalidades ativas

### 2. Hospedagem Web

O projeto pode ser hospedado em qualquer servidor web estático, como:
- GitHub Pages
- Netlify
- Vercel
- Firebase Hosting

## 📱 Recursos Responsivos

- **Desktop**: Experiência completa com todas as funcionalidades
- **Mobile**: Layout otimizado com modal informativo para limitações do PDF

## 🎨 Personalização

### Modificar Informações Pessoais

Edite o arquivo `index.html` para atualizar:
- Nome e informações de contato
- Experiências profissionais
- Formação acadêmica
- Habilidades e certificações

### Customizar Aparência

No arquivo `assets/css/styles.css`, você pode modificar:
- Cores do tema (variáveis CSS no topo do arquivo)
- Tipografia e espaçamentos
- Layout responsivo

### Adicionar Funcionalidades

O arquivo `assets/js/script.js` contém a lógica para:
- Alternância de modo escuro
- Geração de PDF
- Modal responsivo

## 🌙 Modo Escuro

O modo escuro utiliza:
- localStorage para persistência da preferência
- Variáveis CSS para alternância de cores
- Transições suaves entre temas

## 📄 Exportação PDF

**Funcionalidade disponível apenas em desktop**

- Geração automática com nome de arquivo personalizado
- Qualidade otimizada para impressão
- Formatação preservada do layout original
